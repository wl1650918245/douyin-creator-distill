# 账号经营分析

## 目标

“账号经营”用于读取本人已登录的官方创作者中心，按天保存账号概览和近期作品经营指标。它与“抓主页目录”不同：目录回答发布了什么，经营快照回答这些作品在后台的播放、观看和转化表现如何。

## 账号绑定

设置中心允许把经营分析绑定到两种现有账号角色：

- 内容采集账号：适合采集账号就是本人运营账号的情况。
- 收藏夹账号：适合收藏夹账号同时是本人运营账号的情况。

两种用途可共用同一 Chrome Profile，也可独立登录。经营分析只读取所选角色的登录态，不复制 Cookie，不把凭据写入报告。

## 执行流程

```text
手动执行 / 每日调度
  -> 等待所选 Chrome Profile 的唯一执行位
  -> 打开官方创作者中心
  -> 验证账号与数据中心权限
  -> 读取账号概览和后台近期作品指标
  -> 写入 SQLite 历史快照
  -> 保存原始 JSON 和中文 Markdown 日报
  -> 页面展示本次结果以及与上一份快照的差值
```

每日调度默认间隔为 1,440 分钟。服务每分钟检查一次是否到期，但只有到期时才打开浏览器。手动执行与定时执行共用同一运行锁；已有任务运行时不会重复创建第二个任务。

## 保存内容

SQLite 使用四张独立表：

| 表 | 作用 |
| --- | --- |
| `creator_analytics_settings` | 每日开关、间隔、下次执行时间和最近错误 |
| `creator_analytics_runs` | 每次运行状态、阶段、错误与产物路径 |
| `creator_account_snapshots` | 账号级指标的不可覆盖历史快照 |
| `creator_work_snapshots` | 本次后台时间窗口内的作品级指标 |

文件默认保存到：

```text
<知识资产根目录>/analyses/account-operations/<抖音号>/
  YYYYMMDD-HHmmss-snapshot.json
  YYYYMMDD-HHmmss-daily.md
```

账号快照包含关注、粉丝、累计获赞、后台统计周期、周期播放、主页访问、分享和评论。作品快照包含播放、平均观看、2 秒跳出、完播、点赞、评论、收藏、分享、主页访问、关注与取关等后台实际提供的指标。字段缺失时保存为 `null`，不以 `0` 冒充。

## 安全边界

- 只读，不发布、删除、评论、私信或修改账号资料。
- 不采集收入、私信正文和评论正文。
- 不绕过验证码，不在登录失效时伪造空快照。
- 通过已登录浏览器观察官方页面返回的数据，不在后台直接拼接或重放未公开签名请求。
- 同一 Chrome Profile 串行使用，避免多个任务抢占登录目录。

## 已知边界

- 作品级指标来自创作者中心当前时间窗口，不等同于全部历史作品。
- 页面结构和内部数据响应可能调整，解析失败会写入运行记录并等待修复。
- 第一份快照只能形成基线；至少两份快照后，粉丝等累计指标才有日际差值。
- 平台页面显示数据每天更新一次，因此高频采集没有额外价值。

## 验收标准

1. 能识别设置中心绑定的实际运营账号。
2. 运行成功后 SQLite、JSON、Markdown 和页面数量一致。
3. 中文日报无乱码，且包含真实快照时间和数据边界。
4. 开启每日分析后保存 `next_check_at`，服务重启后仍保留调度状态。
5. 登录失效、Profile 占用或页面结构变化时明确失败，不写入成功快照。
