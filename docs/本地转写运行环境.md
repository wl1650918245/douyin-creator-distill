# 本地转写运行环境

## 目标

本项目必须作为独立智能体运行。运行时不得引用 `video_cut`、旧版 `douyin-downloader`、全局 Skill 或其他无关项目的程序、模型和虚拟环境。

当前项目内运行目录：

```text
runtime/
  bin/ffmpeg/ffmpeg.exe
  models/faster-whisper-small/
  python/.venv/
  python/requirements.txt
  python/embedding-requirements.txt
```

其中二进制、模型和虚拟环境体积较大，不提交 Git；发布安装包时由打包流程复制，或由首次安装向导下载到上述固定位置。

## 依赖诊断

首次安装先在项目根目录执行：

```powershell
npm run setup:python
```

该命令只创建 `runtime/python/.venv/`，不会修改系统 Python，也不会引用其他项目虚拟环境。

在项目根目录执行：

```powershell
npm run doctor
```

诊断必须检查：

1. Agent 内 FFmpeg 文件是否存在且可执行。
2. Agent 内 Whisper 模型是否完整。
3. Agent 内 Python 是否存在。
4. `faster-whisper` 是否可以导入。
5. `torch`、`transformers` 与 `sentence-transformers` 是否可以同时导入。

诊断不读取 API Key，不发起抖音抓取，也不消耗云端额度。

本地媒体烟雾测试：

```powershell
npm run whisper:smoke -- "D:\path\to\test.mp4"
```

该命令会在系统临时目录生成 Markdown、JSON 和 SRT，用于确认 FFmpeg 与 Whisper 的真实闭环。

## 抖音本地转写链路

```text
用户选择作品
  -> 选择“Whisper 优先”，或由“云端优先”在额度耗尽后续接
  -> 从专用抖音 Chrome Profile 临时导出 Cookie
  -> 项目内 yt-dlp 下载视频
  -> 项目内 FFmpeg 提取 16kHz 单声道音频
  -> 项目内 faster-whisper 转写
  -> 写入 Markdown、逐段 JSON、SRT、manifest.json
  -> 默认删除下载的视频和临时音频
```

Cookie 仅写入知识资产根目录的 `.runtime/cookies/`，不提交 Git。视频下载和 Whisper 转写保持串行，避免同时抢占专用 Chrome Profile 和本机算力。

转写批次不限制作品总数。云端优先任务达到本地统计的每日 100 条参考值，或云端接口明确返回额度耗尽后，剩余视频自动进入上述本地链路；普通网络超时会先按有限重试处理，不会被误判为额度耗尽。Whisper 优先任务遇到图文或本地单条失败时改用云端。每条作品的实际通道写入 SQLite 并展示在内容列表。

## 产物规范

每条作品使用独立目录：

```text
raw/transcripts/<博主>/douyin_YYMMDD_<标题摘要>_<videoId>/
  manifest.json
  source-metadata.json
  douyin_YYMMDD_<主题>_whisper.md
  douyin_YYMMDD_<主题>_whisper.json
  douyin_YYMMDD_<主题>_whisper.srt
```

目录名称中的发布日期和标题摘要用于识别作品，末尾完整 `videoId` 用作唯一索引。标题摘要会清理 Windows 非法字符并限制长度，避免路径过长。

云端链接提取与 Whisper 不强制输出完全相同的正文：

- 云端 Markdown 使用 `raw/get-notes/<博主>/douyin_YYMMDD_<标题摘要>_<videoId>.md`。
- 云端通道保留整理内容、音频原文、标签和附件。
- Whisper 保留原文、逐段时间轴、词级时间戳和 SRT。
- `manifest.json` 负责索引同一作品的不同通道产物。
- 爆款拆解和知识蒸馏优先读取已完成的 Whisper；没有 Whisper 时读取云端原文。

## 对外打包边界

当前 FFmpeg 为 GPL 构建。内部本地使用已经验证；对外销售或分发安装包前，必须单独完成许可证审查，或改为安装器引导用户安装兼容构建。本文件只记录工程边界，不构成法律意见。

如果安装包不直接携带大文件，安装向导必须：

1. 明确显示 FFmpeg、模型和 Python 依赖的下载位置、体积和用途。
2. 下载后校验文件完整性。
3. 只写入当前 Agent 的 `runtime/`。
4. 自动执行 `npm run doctor`。
5. 诊断失败时给出具体缺失项，不能只显示“启动失败”。
