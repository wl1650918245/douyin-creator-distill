# Demo 验收说明

更新时间：2026-07-28

## 1. 启动

双击项目根目录的 `start-app.cmd`，或执行：

```powershell
npm start
```

访问 `http://127.0.0.1:8780/`。不要直接双击 `index.html`。

## 2. 建议验收路线

1. 打开“内容工作台”，确认可输入主页、单条作品或点击“抓取我的收藏夹”。
2. 打开“关注与更新”，确认博主和收藏夹在左侧切换，能设置每日/每周检查、立即检查、暂停和取消关注。
3. 打开“任务中心”，确认状态与任务类型采用紧凑筛选，任务保留进度、日志和产物入口。
4. 打开“爆款拆解”，查看已有真实报告，并点击“基于这份报告生成选题”。
5. 打开“选题顾问”，确认能看到 2 份证据报告和已生成选题卡片，卡片显示置信度、拍前核验、风险及来源数量。
6. 打开“博主智能体”，选择“飞天闪客”，确认显示 6 条材料、试用画像、画像正文和最近稿件审阅。
